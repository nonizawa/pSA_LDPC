# License recommendation

No license statement was found in the research directory. This staging package therefore does **not** grant a public software or data license. The repository owner must select and add the final license before public release.

## Software options

- **BSD-3-Clause — recommended default for this academic code.** Permissive reuse with attribution and an explicit nonendorsement clause.
- **MIT.** Short, widely recognized, and permissive; it lacks BSD's explicit nonendorsement wording.
- **Apache-2.0.** Permissive and includes an explicit patent grant and contribution terms; longer and more formal.

Before choosing, confirm that every copied source file is owned by the author or is compatible with the selected license. Third-party packages remain governed by their own licenses and are dependencies, not vendored code.

## Data and documentation

A separate data license is advisable. **CC BY 4.0** permits reuse with attribution; **CC0 1.0** maximizes unrestricted reuse. Creative Commons licenses should generally cover data and documentation, not the software source.

## Required release action

1. Select the software license.
2. Add its complete text as `LICENSE`.
3. Select and state the data/documentation license in `README.md`.
4. Record the decision in `CITATION.cff` and the first public release notes.
