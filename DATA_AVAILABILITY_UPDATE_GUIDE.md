# Data Availability update guide

The manuscript currently contains placeholders because no public repository or
archive exists. After public release, replace them only with verified values:

```text
GitHub repository: <TO_BE_INSERTED>
GitHub release/tag: <TO_BE_INSERTED>
Zenodo DOI: <TO_BE_INSERTED>
Optional full-trajectory archive DOI: <TO_BE_INSERTED>
```

The final statement should say that the repository contains simulation code,
the BP reference decoder, selected parameter packages, optimization records,
matrices/formulas and their hashes, compact raw/count data, processed data for
all figures and tables, validation tests, and the pSA-specific transfer,
initialization-robustness, and binary-state-control records. If full trajectories
are deposited separately, cite that archive explicitly.

Do not describe the manuscript as published or insert journal/DOI metadata until
those identifiers exist.
