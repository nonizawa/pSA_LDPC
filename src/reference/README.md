# Validated reference drivers

This directory preserves the module boundaries and internal filenames of the validated research drivers so that numerical behavior remains traceable to the evaluated implementation. Some filenames, command-line flags, generated-report templates, and variable names therefore retain earlier experiment-management terminology.

Repository users should normally invoke the scientifically named entry points under `scripts/`. Public documentation, configurations, instance identifiers, and paper mappings use the study names in the manuscript. No reference driver depends on a personal absolute path; the public launchers supply repository-relative parameter and output locations.
